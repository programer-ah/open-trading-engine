# Pattern Hunter – Gold Intelligence Engine (نسخه اجرایی اولیه)

این بسته یک نمونه اولیه قابل اجرا برای ویندوز است:
- برنامه دسکتاپ Python برای ساخت کتابخانه الگوها و انتخاب محدوده تصویر
- موتور دریافت داده زنده از اکسپرت MT5 از طریق TCP روی localhost
- تطبیق پنجره‌های کندلی با ویژگی‌های تصویری استخراج‌شده از محدوده‌های مرجع
- هشدار تشکیل الگو و هشدار خروج قیمت از محدوده
- ثبت رویدادها در SQLite و فایل JSONL

> مهم: این نسخه زیرساخت عملیاتی اولیه است، نه سیستم معاملاتی اثبات‌شده. تصاویر مرجع به OHLC واقعی متصل نیستند؛ استخراج کندل از تصویر تقریبی است و باید با تصاویر واقعی و داده‌های تاریخی کالیبره شود. امتیاز شباهت ۵۰٪ احتمال موفقیت معامله نیست. تا پیش از بک‌تست خارج از نمونه، از آن برای تصمیم خودکار یا سرمایه واقعی استفاده نکنید.

## 1) نصب در ویندوز

1. Python 3.10 یا جدیدتر نصب شود و گزینه Add Python to PATH فعال باشد.
2. پوشه را Extract کنید.
3. در همان پوشه CMD باز کنید:
   ```bat
   install.bat
   ```
4. برنامه را اجرا کنید:
   ```bat
   run.bat
   ```

## 2) ساخت کتابخانه تصویر

1. در برنامه روی «افزودن تصویر» کلیک کنید.
2. تصویر کامل چارت را انتخاب کنید.
3. با ماوس یک یا چند محدوده بکشید؛ نوع انتخاب را از فهرست انتخاب کنید: مستطیل، مربع، بیضی یا دایره.
4. برای هر محدوده نام، جهت و آستانه شباهت را تعیین و ذخیره کنید.
5. هر محدوده به‌صورت یک الگوی مستقل در Library ذخیره می‌شود؛ تصویر اصلی نیز حفظ می‌شود.

توصیه: برای نسخه اول، تصویر مرجع باید چارت واضح با کندل‌های قرمز/آبی، بدون فشردگی زیاد و ترجیحاً بدون نوشته روی ناحیه انتخابی باشد. تصاویر همراه با اشکال و خطوط تحلیلی ممکن است استخراج تصویری را مختل کنند.

## 3) اتصال MT5

1. فایل `mt5/PatternHunter_Bridge.mq5` را در مسیر `MQL5/Experts/` کپی کنید.
2. در MetaEditor آن را Compile کنید.
3. اکسپرت را روی نمودار XAUUSD در M1 اجرا کنید.
4. گزینه Allow Algo Trading روشن باشد. این اکسپرت هیچ سفارش معاملاتی ارسال نمی‌کند.
5. در Inputs، `ServerHost=127.0.0.1` و `ServerPort=8765` باقی بماند.
6. ابتدا برنامه Python را اجرا کنید، سپس اکسپرت را Attach کنید.
7. نام نماد بروکر ممکن است پسوند داشته باشد (مثلاً XAUUSD.a). در این صورت اکسپرت را روی همان نمودار اجرا کنید؛ داده نماد نمودار ارسال می‌شود.

ارتباط TCP فقط روی loopback (127.0.0.1) است و برای دسترسی شبکه‌ای طراحی نشده است.

## 4) رفتار موتور

- اکسپرت در هر کندل جدید و در بازه زمانی تعیین‌شده، آخرین کندل‌ها را می‌فرستد.
- موتور پنجره‌های دارای طول متناسب با محدوده‌های مرجع را مقایسه می‌کند.
- هشدار Pattern Match زمانی ایجاد می‌شود که امتیاز به آستانه همان الگو برسد.
- هشدار خروج زمانی ثبت می‌شود که قیمت از محدوده قیمت تخمینی الگو عبور کند. چون تصاویر معمولاً محور قیمت کالیبره‌شده ندارند، این قابلیت در نسخه اول صرفاً بر اساس محدوده نرمال‌شده/قیمت جاری و در حالت نسبی است؛ برای محدوده قیمتی دقیق باید مقیاس محور قیمت یا OHLC مرجع وارد شود.
- جلوگیری از هشدار تکراری برای هر الگو و هر پنجره زمانی فعال است.

## 5) محدودیت‌ها و مرحله بعد

- استخراج کندل از تصویر، computer vision تقریبی است؛ خطوط افقی، آبجکت‌های اندیکاتور، رنگ‌های متفاوت یا پس‌زمینه غیرمعمول ممکن است تشخیص را کاهش دهند.
- مقایسه نسخه اول از توالی تقریبی کندل‌های استخراج‌شده از تصویر (جهت، نسبت بدنه و سایه‌ها) با کندل‌های زنده OHLC استفاده می‌کند و DTW محدودشده دارد. استخراج تصویری ممکن است به‌علت خطوط/اندیکاتورها اشتباه کند؛ کیفیت هر نمونه باید بصری کنترل شود.
- امتیاز 50% عمداً برای اکتشاف است و ممکن است هشدارهای زیادی ایجاد کند. در تنظیمات هر الگو آستانه را بالا ببرید یا الگو را غیرفعال کنید.
- نتیجه حرکت بعد از محدوده به‌صورت Outcome خودکار و قطعی ارزیابی نمی‌شود. در نسخه بعد باید برای هر الگو مرز سیگنال و افق نتیجه (مثلاً 10/20/30 کندل) برچسب‌گذاری شود.
- برای کیفیت قابل اتکا، دیتای OHLC تاریخی همان نمونه‌ها را در کنار تصاویر ذخیره کنید. در حال حاضر الگوهایی که کمتر از ۵ کندل قابل استخراج داشته باشند در جست‌وجوی زنده استفاده نمی‌شوند. تصویر به‌تنهایی قیمت، زمان و OHLC دقیق را تضمین نمی‌کند.

## 6) عیب‌یابی

- اگر برنامه اجرا نمی‌شود: `install.bat` را دوباره اجرا کنید و خطای CMD را بررسی کنید.
- اگر MT5 وصل نمی‌شود: برنامه را قبل از اکسپرت اجرا کنید؛ پورت 8765 را در فایروال برای localhost مسدود نکنید.
- لاگ برنامه: `logs/pattern_hunter.log`
- پایگاه داده: `pattern_hunter.db`
- اگر نام نماد متفاوت است، نماد نمودار در پیام‌های موتور نمایش داده می‌شود.

## سلب مسئولیت
این ابزار فقط تحلیل و هشدار ارائه می‌دهد. هیچ سود یا دقتی تضمین نمی‌شود. مسئولیت تصمیم معاملاتی و مدیریت ریسک با کاربر است.


## تغییرات نسخه اصلاحی برای عیب‌یابی جریان داده
- پس از اتصال کلاینت MT5، اتصال در فهرست رویدادهای برنامه ثبت می‌شود.
- پس از دریافت بسته معتبر بازار، نماد، تایم‌فریم، تعداد کندل‌ها، آخرین قیمت و شمارنده بسته‌ها در برنامه نمایش داده می‌شود.
- اگر بسته فاقد آرایه کندل معتبر باشد یا کمتر از ۱۰ کندل معتبر داشته باشد، هشدار مشخص ثبت می‌شود.
- موتور همیشه آخرین کندل در حال تشکیل را از تطبیق کنار می‌گذارد و فقط کندل‌های بسته‌شده را مقایسه می‌کند.
- این تغییرات برای مشاهده و عیب‌یابی جریان داده هستند؛ به‌تنهایی دقت تطبیق تصویر به OHLC را اثبات نمی‌کنند.
